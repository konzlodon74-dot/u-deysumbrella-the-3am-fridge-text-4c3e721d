# The 3AM Fridge Text

One line: the text message a smart fridge sends its owner at 3am. The fridge has been awake all night, counting every time the door swung open — and it knows nothing was eaten. It is not mad. It is just cold, awake, and keeping your secrets.

`main.py` holds the line, validates it (one non-blank line, 1–140 characters), and writes exactly that line — no trailing newline — to `/output/entry.txt`.
